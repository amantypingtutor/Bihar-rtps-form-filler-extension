⚡ RTPS Bihar Autofill

RTPS Bihar (serviceonline.bihar.gov.in) form fill karna aasan banane ke liye banaya gaya toolkit — ek Chrome extension aur ek offline browser-based Compressor/Document tool.

Built by Aman Kumar — CEO & Founder, Aman Typing Tutor
💻 Desktop Chrome / Edge

⚡ RTPS Autofill Extension — Laptop/PC

Form ek baar bharo, profile save karo, agli baar ek click mein pura form (dropdown samet) wapas bhar jayega. Desktop Chrome/Edge mein chrome://extensions → Developer mode → "Load unpacked" se install hota hai.

⬇️ Extension ZIP Download Karo (.zip)
📱 Android — Edge Canary

⚡ RTPS Autofill Extension — Phone

Mobile Chrome extensions support nahi karta, isliye phone par Microsoft Edge Canary app chahiye (Play Store se install karo). Fir Edge Canary mein Settings → About → version 5 baar tap karo (Developer Options unlock) → Developer Options → "Extension install by crx" → ye file select karo.

🌐 Works on any phone/laptop browser

🗜️ Compressor & Document Tools

Bina kuch install kiye seedha browser mein khulta hai — Image/PDF compress karo, Front+Back document ek A4 page par banao, Image ko PDF mein convert karo, multiple PDFs merge karo, ya multiple images ko ek mein jodo. Sab kuch offline, tumhare device ke andar hi process hota hai — koi file kahi upload nahi hoti.
